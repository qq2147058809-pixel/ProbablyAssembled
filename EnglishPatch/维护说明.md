# 独立英文补丁维护

中文表：`../src/Infrastructure/translations.zh.json`，仅嵌入 `PCExpansion.dll`。
英文表：`translations.en.json`，仅嵌入 `PCExpansionEnglishPatch.dll`。
两表使用相同稳定键。普通文本通过键读取；动态文本使用 `{0}`、`{1}` 等模板参数。型号、ID 和存档标签不翻译。

## 日常制作与集中英文更新

维护者在内部开发规则和唯一英文欠更清单中管理更新时机、提醒及清理；这些内部工作区资料不随公开源码发布。下文保留中文本体与独立英文补丁的维护流程。

日常中文内容完成后登记欠更，保留英文表、契约、页面JSON及补丁DLL。`build.ps1` 默认仅构建本体；`deploy.ps1` 默认仅部署本体，保留游戏已有补丁及语言偏好。英文指纹/页面契约不匹配按原机制回退中文。默认包只提供本次中文本体，旧英文DLL不混入为“已同步补丁”。

用户要求集中更新英文后：

1. 对照清单与最新中文内容补齐英文表、手册页、资源/逻辑及相应玩家说明，保留稳定键。`text.<编号>` 是现有固定键，不随翻译重新生成。使用 UTF-8，模板参数索引与中文保持一致。
2. 确认译文已补齐后，更新 `translation-contract.json` 的中文JSON SHA256指纹及键数；需要时同步页面契约。契约更新不能代替实际翻译。业务调用继续使用 `LanguageText.Get` 及延迟 `Argument`，保证回退中文时参数也保持中文。
3. 使用正式 `build.ps1 -UpdateEnglishPatch` 严格校验两表/模板/契约与完整英文页，并配套构建本体和补丁。按该次用户指令使用 `deploy.ps1 -UpdateEnglishPatch` 或 `package.ps1 -UpdateEnglishPatch`；只在游戏已有英文补丁时同步它，不自动启用。
4. 验证译文覆盖、版本接入与拒绝、缺项回退及本次必要行为。实机缺口如实留在交接，不能把文件检查当成画面验收。备份欠更清单并归纳完成范围后，删除已更新并验证的记录；未完成记录继续保留。

## 加载与回退

补丁通过反射调用本体公开的 `InstallEnglishTranslations`，传入独立英文表、接口版本和中文表指纹；本体没有补丁程序集依赖。补丁不注册物品、NPC 或其他玩法。

仅本体时使用中文；有匹配补丁时使用英文；版本不匹配或补丁无有效译文时保持中文；缺失/损坏翻译项回退中文。补丁单独加载时提示缺少本体，不启用译文或玩法。移除补丁并完全重启恢复中文。

正文沿用原版 UI 字体；中文手册独立选取原版简体动态字体并准备所需字形，英文页复用原版TMP模板，本补丁不替换全局字体。源码/资源的 UTF-8、静态检查和编译不能代替游戏字形、窗口排版及存读档验证。2026-10-08集中更新证据位于外部 `analysis/english-patch-current-20261008/`；2026-10-09再次集中同步至509键及十页手册v13。

## 电脑装机交易手册页面

中文二十页为本体 `src/Infrastructure/computer_manual.zh.json` 的163个独立TMP文字/图标元素，使用原版纸背景和页码；早期八张整页PNG不再是当前正文或英文门禁。英文完整二十页在 `manual/computer_manual.en.json`，只嵌入补丁资源 `PCExpansionEnglishPatch.Manual.en.json`；本体独立中文回退保持。

当前JSON契约为 `pcexpansion-computer-manual-v27`，根字段 `contract`、`pages`；每页字段为 `title`、`body`（带换行的纯英文）和 `illustrations`（当前整件物品ID，最多六张；退役螺丝刀ID不接受）。顺序对应简介（两页）、快捷操作、开箱、可修理物品、维修与混合回收（两页）、开机检测、三种机型、机型示例、高端配件、机房快速上手、算法、矿池、容量、维护、服务器、币市、自动出售和经营账本。正文不接受富文本，标题最多100字符，正文最多2600字符。内容必须完整二十页，不能按页混合回退；实际排版超出时整本回退中文。

任何中文页面内容或页序变更，都必须递增本体 `ComputerManualPages.ContractVersion` 并登记欠更，防止旧英文页面被继续接受。集中英文更新时再同步英文JSON的 `contract`、`translation-contract.json` 的 `ManualContractVersion` 及中文门禁版本，并重新核对整本英文内容。英文门禁从本体源码读取当前契约，核对中文布局、英文页序及当前配图PNG。译表指纹只证明译表版本，不能代替页面内容同步。首次八页v1及较早图片正文仅为历史。

补丁先注册有效译表，再反射调用本体 `ComputerManualPages.InstallEnglishManualPages(contract, catalogFingerprint, json)`。页面契约和中文目录SHA256都匹配、语言补丁已启用才接受。缺页、损坏、未知配图或版本不匹配时整本回中文；英文排版或配图创建失败也整本回中文。页面延迟安装时刷新已存在的手册根，正在阅读时保留有效页号。

`translation-contract.json` 维护 `ManualContractVersion`；正式构建增加 `scripts/ValidateComputerManual.ps1` 门禁并单独嵌入英文JSON。英文页沿用原版纸背景与TMP字体，标题、正文和配件插图独立排版，页码使用独立译表 `manual.page.indicator`。中文页只在本手册打开时临时隐藏共用纸背景颜色与页码，保留原版拖动、导航、关闭和音效。字号适配、长配方表、字体覆盖、场景重建和原版手册恢复仍须游戏显示验证。
